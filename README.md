# AquaInSAR

**AquaInSAR investigates groundwater stress by measuring ground deformation from satellite radar and comparing it with groundwater and environmental records.** It is a Conrad Challenge concept from team **The Oopsies**, in the Aerospace & Aviation category.

The core scientific question is whether satellite-derived deformation is a useful regional indicator of groundwater stress in a selected agricultural area of Uttar Pradesh. Subsidence is indirect and can have several causes; AquaInSAR does not yet have validated measurements, a selected pilot district, or an operational prediction service.

## Project status

The repository currently contains project documentation and a competition reference PDF. No processing pipeline, reference datasets, model, or functional dashboard has been evidenced in the repository. Treat the weekly tasks as planned work until deliverables and evidence are reviewed.

## Competition and evidence integrity

The tagline in the original project description is “Predict groundwater collapse from orbit before wells run dry.” Treat it as an aspiration, not a verified capability. Any competition or product claim must be backed by the actual data, method, validation, and uncertainty available at the time. Follow the competition's current rules for originality, intellectual property, and AI disclosure.
